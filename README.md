# Week 7 Assignment: My Notes & The Report Builder

- `my_notes.py` — writes three notes, appends a fourth note, reads the file, and counts the lines.
- `my_notes.txt` — the notes file generated by `my_notes.py`.
- `report_builder.py` — reads learner scores from a CSV, calculates the pass count and average, and writes a report.
- `hubs.csv` — contains the learner names, hubs, and scores used by the report builder.
- `report.txt` — the report generated by `report_builder.py`.

If you changed `"a"` to `"w"` in Question 1, the program would erase the first three notes before writing the fourth note, leaving only `I added this later` in `my_notes.txt`.
